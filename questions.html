Networking Fundamentals

what is a Computer Network?
A computer network is a group of two or more computing devices connected together to communicate and share resource such as file, printer, and internet connections.
What is a WAN?
A wide Area Network links networks across large distance or internet is WAN.
What is the main purpose of a computer network?
The main purpose of computer network is to enable communication and resource sharing between connected devices, making information exchange easier and more efficient.
What is node in computer networking?
A node is any device connected to a network that can send, receive, or forward data.
what is client-server network?
It is a network architecture where client devices request services or resources from a centralized computer called a server.
what is a network switch?
A switch connects multiple devices within a local network and forwards Ethernet frames to the appropriate destination using MAC address.
What is a network hub?
A hub is a basic networking device that connects multiple devices and broadcasts incoming data to all its other ports without identifying the intended destination.
what is the main difference between a hub and a switch?
A hub sends incoming data to all connected devices, while a switch forwards data to the intended destination port based on its MAC address table.
what is a Network Interface Card (NIC)?
A NIC is a hardware component that allows a computer or other device to connect to a network through wired or wireless communication.
wht is a router?
A router is a networking device that connects different networks and forward data packets between them using ip address.
