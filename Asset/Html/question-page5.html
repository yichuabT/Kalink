Networking Fundamentals

what is bus topology?
Bus topology connects multiple devices through a single main communication cable called the backbone. Data travels along this shared cable.
what is star topology?
Star topology connects all devices to a central networking device, usually a switch or hub. Devices communicate through this central device.
what is ring topology?
Ring topology connects devices in a circular arrangement, where each device is connected to its neighboring devices.
what is mesh topology?
Mesh topology connects devices through multiple communication links. It provides alternative paths for data if one connection fails.
which network topology uses a central switch or hub to connect all devices?
Star topology. All connected devices communicate through the central networking device.
what is IPv6?
IPv6 stands for Internet Protocol Version 6. It uses 12i8-bit addresses and was developed to provide a much larger address space than IPv4.
what is the difference between Dynamic IP and Static Ip address?
A static IP address is manually configured or reserved to remain consistent, while a dynamic IP address is addigned automatically, common through DHCP.
what is Network security?
Network security refers to the practices, technologies, and policies used to protect networks, devices, and data from unauthorized access, attacks, and misuse.
what is firewall?
Firewall is a security system that monitors and filters incoming and outgoing network traffic based on predefined security rules.
what is encryption
Encryption is the process of covering readable information (plaintext) into an unreadable format (ciphertext) to protect it from unauthorized access.
