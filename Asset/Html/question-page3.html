Networking Fundamentals

which OSI layer is responsible for transmiting raw bits over a physical medium?
The Physical layer. It handles the transmission of raw bits through cables, radio signals, and other physical media.
which OSI layer is responsible for logical addressing and routing?
The Network layer (Layer 3). It uses logical address, such as IP addresses, to determine how packets travel between networks.
what is the main responsibility of the Transport layer?
The Transport layer provides end-to-end communication between applications. It handles functions such as segmentation, reliability, and flow control depending on the protocol used.
what is the TCP/IP model?
The TCP/IP model is a networking framework that describes how devices communicate over interconnected networks, including the internet.
what is the main difference between the OSI and TCP/IP models?
The OSI model has seven layers and is mainly a reference model, while the commonly used TCP/IP model has four layers and describes the protocol architecture used for internet communication.
what is a network protocol?
A network protocol is a set of rules that determines how devices communicate, exchange, and interpret data over a network.
what is HTTP?
HTTP stands for Hypertext Transfer Protocol. It is ud=sed for transferring web content between web browser and web servere.
what is HTTPS, and how is it different from HTTP?
HTTPS is the secure version of HTTP. It uses TLS encryption to protect data exchanged between a browser and a web server.
what is FTP?
FTP stands for File Transfer Protocol. It is used to transfer files between computers over a network.
what is DNS?
DNS stands for Domain Name System. It translates human-readable domain names, such as google.com, into IP addresses used by computers to locate network services.
