Computer Network Models.

Network Model is a framework dividing network communication into layers, each with its own job and rule.
And Layer is one stage in the model doing one job. It uses the layer below and serves the layer above.

In general there are two types of networking Models:
OSI(Open System Interconnection) and TCP/IP(Transmission Control Protocol/Internet Protocol)

TCP/IP model.

TCP/IP suite, refers to a group of protocols used on modern networks. These protocols provide a end-to-end connection by specifying how data should be segmented, addressed, and routed across network
TCP/IP only have four layers, 4. Application 3. Transport 2. Internet
1. Link

4. Application

This layer of TCP/IP model is equivalent to the Application, Presentation, and Session layers of OSI model.
It handles many functions. e.g Data generation, Compression, Conversion, Translation, and encryption. it also handles session establishment, maintenance and termination.
Note that this layer of TCP/IP model is doing alone what three layers of OSI model does.
Common protocols include: HTTP, Telnet, SSL, FTP, DNS......

3. Transport

This layer is the same as Transport layer of the OSI model.
Main functions are data segmentation, flow control, and error checking. as we discussed on OSI model section, common protocols are TCP and UDP.

2. Internet

This layer of TCP/IP is the same as Network layer of OSI model. main functions are IP addressing and routing.
Common protocols used on this layer are: IPV4, IPV6, ICMP .....
Communications would be limited only on LAN(local area network) without this layer.

1. Link

This layer of TCP/IP model combines both Datalink layer and Physical layer of the OSI model.
The main function of Link layer is frame making, MAC addressing, frame switching, and physical cabling.
Common protocols are: ARP, Ethernet, Token ring, WiFi . . .
