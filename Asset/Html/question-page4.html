Network Fundamentals

what is DHCP?
DHCP stands for Dynamic Host Configuration Protocol. It automatically provides network configuration information, such as IP addresses, to devices joining a network.
what is the difference between TCP and UDP?
TCP provides reliable, connection-oriented data delivery, while UDP is connectionless and does not guarantee delivery or packet ordering. UDP generally has less communication overhead.
what is data communication?
Data Communication is the process of exchanging information between two or more devices through a transmission medium, such as cables or wireless signals.
what are the five basic components of data communication?
Sender, receiver, message, transmission medium, and protocol. Together, they make communication between devices possible.
what is a transmission medium?
A transmission medium is the physical or wireless path through which data travels from a sender to a receiver. Example: include fiber-optic cables, twisted-pair cables, and radio waves.
what is the difference between simplex, half-duplex, and full-duplex communication?
Simplex allows communication in one direction only, half-duplex allows communication in both direction but not simultaneously, and full-duplex allows communication in both directions simultaneously.

what is network topology?
Netork topology refers to the physical or logical arrangement of devices and connections within a computer network.
what is an IP address?
An IP address is a logical address assigned to a network interface to identify it and enable communication using the Internet protocol.
what is IPv4?
IPv4 stands for Internet Protocol Version 4. It uses 32-bit addresses, commonly written in dotted-decimal format, such as 192.168.1.1.
