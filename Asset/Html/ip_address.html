What is IP Address?

IP address is the identity of each host. every host or devices must have IP address in order to communicate on internet.
we need IP address in order to send or receive any packets on a network. when we send a request to some website there will be a source IP address and Destination IP address stamped to the packet. also when the server responds the same thing will happen. the source and the Destination IP address means the sender and receiver IP address.

There are two types of IP address(Internet Protocol Address):
IPv4 and IPv6

what is IPv4?

IPv4 has four octet separated by dots(.) e.g. K.K.K.K
Each octet will have 8 0s and 1s. the range for each octet is 0 - 255 but this decimal numbers is not computer understandable. so these decimal numbers will be converted to Binary digit (0 and 1). e.g 0 - 255 can be written in binary 00000000 - 11111111 you can assume 1 as on and 0 as off that is basically how computer understand 0s and 1s.
as we see each octets represented by eight binary digits, all IPv4 address represented by sequence of 32 0s and 1s or technically 32-bit. IPv4 is a 32-bit address that means all available IPv4 address is 2^32 that means ~ 4,294,967,296 devices can get IPv4 address but as you guessed it is not possible to address all devices across the world, now a days world population is ~ more than 7 Billion. so this is why IPV6 created.

what is IPv6?

IPv6 is 128-bit IP address. simply IPv6 written as a group of eight Hexadecimal numbers separated with colons.
e.g. 211:0DF3:CB20:FF02: 0000:0000:0000:0000 but in computer understanding form can be written by sequence of 128 1s and 0s.
all available addresses can be given for devices all over the world by IPv6 is 2^128. which means ~ 34028236692 093846337460743 1768211456.
Now as you guessed it there is no problem with addressing all devices all over the world to make them connected to internet. because there are more than enough IP addresses using IPv6.

You can check your IP Address just by asking Google. (syntax : What is my IP Address.).

IP address can be classified by: Dynamic IP address and Static IP address.
Dynamic IP Address
when you connect your devices to the Internet, ISP(internet service provider) will provides you an IP address from the range of available IP address so you can connect your device to the internet. then by next time when you connect to the internet, ISP will provides you different IP address from you priviously given. so IP address keeps on changing every time you connec your devices to the internet, they are called Dynamic IP address.

Static IP Address
The ststic IP addresses never change or they are permanent internet addresses. static IP addresses most commonly used by DNS servers. you can understand what DNS is on Computer network protocols module.
Static IP addresses provides information: what device located in which country, which city, and which ISP provides the connection to that device.
